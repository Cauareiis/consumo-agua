# 💧 Consumo de Água

Sistema desenvolvido em Python para classificar o perfil de consumo de água de imóveis e emitir alertas educativos de acordo com o consumo informado.

## 🎯 Objetivo

O objetivo deste projeto é desenvolver um programa em Python capaz de analisar o tipo de imóvel e o consumo mensal de água em metros cúbicos (m³), classificando o perfil de consumo conforme as regras estabelecidas na atividade.

## 📋 Regras do sistema

* 🏢 **Comercial:** exibe a mensagem de tarifa comercial.
* 💧 **Apartamento com menos de 10 m³:** consumo econômico.
* 🏠 **Apartamento ou casa com até 25 m³:** consumo moderado.
* ⚠️ **Outros casos:** consumo excessivo.

## ▶️ Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Acesse a pasta `consumo-agua`.
4. Execute o arquivo `app.py`.

No terminal:

```bash
python app.py
```

Depois, informe o tipo de imóvel e o consumo mensal solicitado pelo programa.
